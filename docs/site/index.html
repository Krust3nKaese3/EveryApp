Rechtliches

EveryApp ist eine Container-App. Mini-Apps aus GitHub laufen als HTML und JavaScript in einer WebView. Es gibt keinen eigenen Server, kein Nutzerkonto und kein Analyse-SDK.

Für GitHub Pages die Quelle /docs auf dem Branch main wählen. Die Datenschutz-URL ist dann https://<owner>.github.io/<repo>/site/datenschutz.html.

Vor der Veröffentlichung {{BETREIBER_NAME}}, {{BETREIBER_ADRESSE}} und {{SUPPORT_EMAIL}} in den Markdown-Dateien ersetzen und node scripts/sync-legal.js ausführen.
